## Brand & Style
The design system establishes a high-performance, focused productivity environment tailored for modern operators, knowledge workers, and technical teams. It embodies focused intentionality, operational clarity, and momentum. The aesthetic fuses Modern Corporate SaaS precision with refined Scandinavian minimalism: ample negative space, strict typographic hierarchy, and low visual noise that prioritizes user data over interface chrome.

The visual tone eliminates distraction to facilitate deep work, creating a calm, frictionless state of accomplishment. Visual weight is reserved strictly for action states, status progression, and priority signaling.

## Colors
The palette leverages a deep indigo and electric violet dynamic for primary interaction points, balanced against a clean slate-neutral foundation to keep the viewport airy and legible.

- **Primary (`#4F46E5` / `#6366F1`):** Represents purposeful action, progress tracking, and key navigation highlights.
- **Surface Neutrals (`#FFFFFF`, `#F8FAFC`, `#F1F5F9`, `#E2E8F0`):** Provide layered structural clarity across cards, sidebars, and base canvas.
- **Typography Neutrals (`#0F172A`, `#334155`, `#64748B`, `#94A3B8`):** Strict hierarchical contrast tiers ensuring AA/AAA compliance across all reading scales.
- **Semantic Accents:**
  - **Success Emerald (`#10B981`):** Task completions, milestone achievements, positive velocity metrics.
  - **Warning Amber (`#F59E0B`):** Impending deadlines, blocked dependencies, pending assignments.
  - **Critical Rose (`#EF4444`):** High-priority alerts, overdue tasks, destructive actions.

## Typography
The system employs a dual-font pairing to establish immediate structural authority. Plus Jakarta Sans handles titles and metrics with contemporary geometric polish, while Inter delivers exceptional screen legibility across dense checklists, metadata, and task descriptions.

### Usage Rules
- All numeric indicators (due dates, task counts, subtask counters) must use `label-md` or `label-sm` with tabular figure alignments (`font-variant-numeric: tabular-nums`).
- Section titles and modal headers use `headline-md` with strict negative tracking to preserve horizontal space.
- Overdue or status badges rely exclusively on uppercase `label-sm` with slight positive tracking (`0.02em`).

## Layout & Spacing
Layouts use an 8pt base grid for element sizing and interior spacing, paired with a 12-column responsive fluid grid system on desktop that condenses into a single stacked column on mobile.

- **Desktop (1200px+):** Fixed collapsible global rail (64px mini / 240px expanded), multi-column kanban or nested list views utilizing `gutter` (1.5rem) and standard section `margin` (2rem).
- **Tablet (768px - 1199px):** 8-column layout; secondary panels (task detail drawers) slide over as modals or overlays rather than persistent right-hand panes.
- **Mobile (<768px):** Single-column layout with fixed bottom navigation bar (56px) and a persistent floating quick-add trigger button offset by `space-md` from screen bounds.

## Elevation & Depth
Depth is created through ambient diffused drop shadows and crisp border definitions (`#E2E8F0`), avoiding muddy drop-shadows or stark dark glows.

- **Level 0 (Flat Base):** Canvas background (`#F8FAFC`) with no shadow.
- **Level 1 (Cards & Task Items):** Background `#FFFFFF`, border `1px solid #E2E8F0`, shadow `0 1px 3px 0 rgba(15, 23, 42, 0.05), 0 1px 2px -1px rgba(15, 23, 42, 0.05)`.
- **Level 2 (Hover & Drag States):** Elevated task items and active dropdown triggers apply `0 10px 15px -3px rgba(15, 23, 42, 0.08), 0 4px 6px -4px rgba(15, 23, 42, 0.04)`.
- **Level 3 (Modals & Command Palette):** Task creation dialogs and quick-search panels use `0 20px 25px -5px rgba(15, 23, 42, 0.1), 0 8px 10px -6px rgba(15, 23, 42, 0.06)`, framed by a delicate border `1px solid #CBD5E1`.

## Shapes
Cards, task containers, and detail panels employ standard medium roundedness (`rounded-lg` at 1rem, `rounded-xl` at 1.5rem) to reinforce modern software ergonomics without feeling overly informal. Interactive controls such as standard text inputs, select dropdowns, and button elements use 0.5rem (`rounded-md`). Status pills, priority tags, and user avatars retain a circular or fully rounded format (`rounded-full`) to contrast against rectangular content blocks.

## Components

### Buttons
- **Primary:** Solid `#4F46E5` fill, `#FFFFFF` text, `0.5rem` border radius, subtle hover shift to `#4338CA`. Active state scales down slightly (`scale(0.98)`).
- **Secondary:** Surface `#FFFFFF`, border `1px solid #E2E8F0`, text `#334155`. Hover transitions to background `#F8FAFC` and border `#CBD5E1`.
- **Destructive:** Background `#FEE2E2`, text `#DC2626`, hover background `#FCD34D` tinted to critical rose.

### Task Item Row
- Default row container features a white surface, `1px solid #E2E8F0` border, `space-md` horizontal padding, and dynamic hover state revealing quick-action icons (snooze, assign, delete).
- Completed tasks toggle a linear strike-through on titles, desaturate priority tags, and drop row opacity to `0.55`.

### Checkboxes
- Circular or soft-cornered square (0.25rem radius), `18px` diameter.
- Unchecked: `1.5px solid #CBD5E1`, transparent interior.
- Checked: `#10B981` solid fill, white centered checkmark glyph with a micro-scale bounce animation (150ms ease-out).

### Input Fields
- White fill, `1px solid #E2E8F0`, padding `0.625rem 0.875rem`, font size `14px`.
- Focused state: Border transitions to `#4F46E5` with an outer ring glow of `0 0 0 3px rgba(99, 102, 241, 0.15)`.

### Priority Badges & Chips
- **High Priority:** `#FEE2E2` background, `#EF4444` bold text, inline flame or chevron indicator.
- **Medium / Pending:** `#FEF3C7` background, `#D97706` text.
- **Low / Backlog:** `#F1F5F9` background, `#64748B` text.
- Height is fixed at `22px` with uppercase `label-sm` font sizing and `rounded-full` pill structure.

### Command Palette & Quick Add
- Centered overlay modal with backdrop filter blur (`backdrop-blur-sm`, `rgba(15, 23, 42, 0.4)`).
- Direct keyboard-accessible input row at top with shortcut badges (`⌘K`, `Enter`, `Esc`) displayed in muted `#94A3B8` mono containers.
